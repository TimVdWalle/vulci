# Vulci Naming Decision

## `name-001` — Accepted decisions

- The programming language is named **Vulci**.
- Vulci source files use the extension **`.vulci`**.
- Both decisions may be revised later.
- Until explicitly revised, **Vulci** and **`.vulci`** are the accepted project decisions.

## Context and reasoning

The project needed a practical working name that could also remain the permanent language name.

Names from real places were considered because they are neutral, memorable, and do not tie the language to a specific feature or implementation detail.

**Vulci** was chosen because the project began while its creator was staying near the ancient city of Vulci. This gives the name an authentic origin story rather than a manufactured technical meaning.

The name was also preferred because it is:

- short;
- distinctive;
- easy to pronounce;
- easy to search for;
- suitable for a programming language;
- not dependent on a feature that may later change.

Several file extensions were considered, including `.vci`, `.vu`, and `.vulci`.

The accepted extension is **`.vulci`** because it is explicit, recognizable, and directly matches the language name.

## Status

These are accepted project decisions, but they are not irreversible.
